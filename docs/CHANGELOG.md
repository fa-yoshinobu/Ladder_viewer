- `npm run windows:build` を追加。EXE・起動方法・第三者ライセンスを含む配布用ZIPも作成。

- 別PCでの動作、署名付きインストーラーは未検証・未作成。

### 挿入・削除に伴う行ずれ対策

- CSVの同じ行・同じステップ番号だけで比較せず、命令と引数の並びを `diffArrays` で対応付ける方式へ変更。
- 元CSVの行番号は左右別々に保持し、対応付け用の番号と分離。
- 挿入・削除箇所に空き行を入れ、後続の回路や分岐出力の縦位置を揃える処理を追加。
- 命令が同じでステップ番号だけ移動した箇所は内容差分から除外し、無着色に変更。移動行数は別表示。
- `変更ありの比較CSV` は現在の方式で内容差分24行、ステップ移動323行となることを確認。ただし、24行はアルゴリズムの算出結果であり、人が全対応を照合した正解件数ではない。

### 配線の接続差分

- 接点・命令の入出力端子と配線の交点から接続集合を作り、左右の直結先を比較する処理を追加。
- 元だけの接続を赤、先だけの接続を緑で表示。接点・命令につながる短い線にも反映。
- 行パディングで線が長くなるだけの場合は無着色。共通母線や無関係な既存回路を一括着色しないようにした。
- `変更ありの比較CSV` の元対象回路付近で、接点とパルス接点によるOR合流が失われる箇所を確認。元の中央縦線・下段横線を赤、先の独立した出力接続を緑で表示。
- 共通の接点とパルス命令の直列接続は無着色のままとなることを確認。

### 既知の制限

- 命令列全体を先に照合するため、繰返し回路や回路の入替えで境界を跨いだ誤対応が起こり得る。
- 連続した削除・追加を順番に組み合わせるため、関連のない命令も「変更」扱いになり得る。
- 配線差分は命令の対応結果と描画グリッドから復元した接続に依存する。回路対応の正しさまで保証するものではない。

### 基本ビューア

- GX命令リストのタブ区切りCSV、UTF-16LE/BE・UTF-8・Shift_JISの読込み。
- Preact + SVG、固定12列、長い回路の折返し、表示範囲周辺のみの描画。

- フォルダー・複数CSVの一括読込み、プログラム切替、COMMENT.csvのデバイスコメント表示。
- P番号のラベルを左側へ表示。ステートメントは全幅の水色帯に表示。
- `Z0` / `LZ0` などのインデックス指定部は番号まで紫色で表示。
- 純正画像は参考資料に限定し、ビューアの表示・配布には使用しない。

### 比較CSVの表示

- 照合元・照合先を左右に表示し、縦スクロールを連動。
- 変更を黄色、追加を緑、削除を赤で表示。
- 基準版では変更した文字・引数を濃い茶色、太字、下線で強調し、共通の文字は通常色を維持していた。追加・削除の命令全体にも文字強調を付けていたが、上記の修正で背景色だけにする対象。
- 背景色は命令単位、文字の強調は命令内の差分、青い枠は選択中を示す。インデックス指定部の紫色は別の意味。
- 差分の前後移動、差分行の選択、左右の命令プレビュー、元CSV行の確認。
- 当初はステップ番号だけの差分も青で着色していたが、現在のローカル版では上記の通り内容差分から除外。
