## 0.3.0（2026-10-25）

- 比較画面の回路一覧が240pxに広がり、幅に合わせたときに比較画面がはみ出していた不具合を修正した（170pxに戻した）。
- スタイルシートを整理し、使われていない指定と重複した上書きを除いた。表示は変えていない。
- 起動用の `start-viewer.cmd` を削除した。EXEを直接起動する。
- 改行コードを `.gitattributes` で統一した。

## 0.2.0（2026-10-25）

- 実行環境を .NET 8 から .NET 10（LTS）へ移行した。.NET 8 のサポートは2026年11月10日に終了する。起動には .NET 10 Desktop Runtime（x64）が必要。

## 0.1.0（2026-10-25）

- 画面をデジタル庁デザインシステム（DADS）の配色・文字サイズ・フォーカス表示に合わせて整理した。文字を基本14pxに拡大し、上部の操作欄を2段にまとめた。
- ダークモードを追加した。初回はWindowsの設定に従い、右上のボタンで切り替えた結果を記憶する。
- ラダー図の配色プリセット（標準・高コントラスト・目にやさしい・色覚配慮（CUD）・ブルー）を追加した。ライト・ダークそれぞれに配色があり、選択はモードごとに記憶する。ライトモードの「標準」は従来の表示と同じ。
- 比較の凡例の配線色を、色名ではなく線の見本で示すようにした。
- アプリアイコンを追加し、EXE・ウィンドウ・画面左上に表示するようにした。
- 「バージョン情報」をブランド帯付きの画面に作り直した。使用ライブラリを表で示し、ダークモード時は暗い配色で表示する。
- ウィンドウの大きさを変えたときと、比較の表示（左右比較・比較元のみ・比較先のみ）を切り替えたときに、幅に合わせ直すようにした。
